# 403 Restricted origination number D54

This error code indicates that Telnyx has blocked an outbound call attempt to the PSTN because the origination number has a bad reputation.

Telnyx has introduced this new security mechanism to combat unsolicited calls by screening outbound call attempts and blocking them if the origination number has a bad reputation.

The number reputation data is built by aggregating multiple data sources and it’s constantly being updated.

If you believe your origination number has been incorrectly flagged please contact our support team via chat or email ([support@telnyx.com](mailto:support@telnyx.com)).
